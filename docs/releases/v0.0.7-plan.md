# План Pixprite 0.0.7 — цвет, нажим и текст

Составлен 9 ноября 2026 года. Релизный срез: **0.0.7**. Автоматические локальные
проверки пройдены; публикация пакетов выполняется после desktop-матрицы GitHub CI.
Формат `.pixprite` не меняется. Фактические изменения описаны в
[заметках 0.0.7](v0.0.7.md).

Ручная приёмка планшета и системных UI в этом плане остаётся открытой: запрос
пользователя на выпуск не является свидетельством проведения этих проверок.

## Результат для пользователя

Одним движением пера можно рисовать участки с разной прозрачностью, цвет задаётся
прямо в COLOR, а существующие настройки нажима и стабилизатора легко найти.
Текстовый инструмент сохраняет пробелы, корректно обновляет предпросмотр и
не теряет ввод при применении и переходах между документами.

## Обязательные цели

| Цель | Реализация | Оставшаяся приёмка |
| --- | --- | --- |
| Локальная alpha от нажима | Коэффициент хранится у точек штриха; Pixel Perfect использует записанные значения | Настоящий планшет: модель, ОС и настройки |
| Popup цвета в COLOR | HEX, RGB/A, системный выбор, desktop API экранной пипетки, перенос сообщений | Настоящие системные диалоги и захват пикселя на целевых ОС |
| Понятные настройки пера | Кнопка «Перо», явные подписи, сила стабилизатора 0–64, сохранение настроек и старых пресетов | Качество линий и совместная работа на планшете |

### 1. Прозрачность меняется только у новых пикселей штриха

- [x] Сохранять вычисленный коэффициент opacity при добавлении точки. Промежуточные пиксели получают нажим события, которое их добавило; интерполяции нажима нет.
- [x] При повторной отрисовке Pixel Perfect переносить коэффициенты сохранившихся точек, включая очистку углов.
- [x] Проверить размер 1 и 6, «Чистые линии» вкл./выкл., ластик, пользовательскую кисть, мышь и отключённую привязку нажима.
- [x] Сохранить семантику одного нанесения: повторно затронутый пиксель сохраняет первый результат, остальная линия не пересчитывается.
- [x] Доводить хвост стабилизатора до точки отпускания с последним контактным нажимом и размером кисти.
- [x] Сохранить один шаг undo на штрих и точное восстановление PNG после redo.
- [ ] Подтвердить поведение на реальном планшете с записью модели, ОС и настроек. Синтетические pen-события не проверяют драйвер устройства.

Регрессии: [pen-pressure.e2e.ts](../../e2e/pen-pressure.e2e.ts). Сравниваются
живые участки до отпускания и alpha экспортированного PNG, а не только скриншот.
Отдельный режим прозрачности всей линии остаётся в бэклоге.

### 2. Редактирование цвета по нажатию на COLOR

- [x] Независимые основной/фоновый образцы открывают popup; вкладка HSL/HSV/RGB сохраняется.
- [x] HEX поддерживает RGB/RGBA/RRGGBB/RRGGBBAA, необязательный `#` и пробелы по краям. Недопустимый ввод сохраняет последний допустимый цвет.
- [x] HEX, R/G/B/A (0–255), образцы и picker синхронизированы. RGB и системный выбор сохраняют текущую alpha; RGBA и канал A меняют её явно.
- [x] Проверить ввод, клавиатуру, закрытие кнопкой/Escape/снаружи, фокус и отсутствие команд холста при вводе.
- [x] Добавить desktop API: NSColorSampler на macOS, Win32 на Windows, XDG PickColor на Linux. В браузере используется EyeDropper при наличии поддержки.
- [x] Отмена/ошибка не применяют результат, закрытие popup отменяет незавершённый захват. Сообщения переносятся в узком popup.
- [x] Проверить русский/английский UI, крупный шрифт, 800×600 и ширину панели 220/360 px.
- [ ] Проверить настоящие системные диалоги, захват цвета вне холста и отмену на macOS/Windows/Linux. Проверка native-адаптера с подменённым результатом не заменяет UI ОС.

Регрессии: [color-popup.e2e.ts](../../e2e/color-popup.e2e.ts),
[panel-layout.e2e.ts](../../e2e/panel-layout.e2e.ts),
[screen-color.test.ts](../../desktop/screen-color.test.ts) и Rust `screen_color::tests`.

### 3. Настройки пера и стабилизатора можно найти и настроить

- [x] Подписать кнопку «Перо» в параметрах карандаша, ластика и распылителя. При нехватке места она находится в «Другие параметры инструмента».
- [x] Дать явные подписи «Нажим → размер/прозрачность», «Минимум, %»; распылитель также поддерживает привязку плотности.
- [x] Подписать стабилизатор карандаша/ластика, сохранить диапазон 0–64 (0 полностью отключает его).
- [x] Проверить сохранение общих настроек нажима, восстановление стабилизатора в editor-состоянии и старых пресетах. Привязка нажима к каждому пресету — отдельная будущая задача.
- [ ] Проверить медленные/быстрые движения, начало и завершение линий на планшете. Новый алгоритм сглаживания не входит в этот выпуск.

Регрессии: [pen-settings.e2e.ts](../../e2e/pen-settings.e2e.ts), включая крупный
русский/английский интерфейс с включёнными привязками и видимым минимумом.

## Текстовый инструмент

Пользователь уточнил, что неверны пробелы и отрисовка текста. ОС и версия исходного
наблюдения не сообщены. Найденные локальные причины воспроизведены автоматически.
Это исправление растрового инструмента; редактируемые текстовые слои не добавляются.

- [x] Сохранять логическую ширину пробелов и выступы глифов; начало поля — верхний левый угол точки нажатия.
- [x] Поддержать многострочную вставку и Shift+Enter; Enter применяет, Escape отменяет текст.
- [x] Удалять старый bitmap после полной очистки. Пустой текст и одни пробелы не создают нанесение и шаг undo.
- [x] Обновлять текст при смене шрифта, размера, начертания, сглаживания и цвета; поля параметров сохраняют фокус.
- [x] Перетаскивать живой текст и продолжать ввод; каждая применённая рамка — один шаг undo.
- [x] Дожидаться шрифта перед применением, в том числе в WebKit; не восстанавливать отменённый текст после загрузки.
- [x] При очистке перемещённого текста сохранять новую позицию для следующего ввода.
- [x] Завершать ввод перед переключением документа, Home/вкладкой сравнения, созданием/закрытием документа, дублированием и явным сохранением. Переходы учитывают завершение загрузки шрифта.
- [ ] Добавить конкретный проблемный текст/проект пользователя в регрессии при его получении; набор тестов не доказывает отсутствие любых проблем текста.

Регрессии: [text-tool.e2e.ts](../../e2e/text-tool.e2e.ts). При повторном разборе
сценарии позиции после очистки и переключения вкладки сначала упали на исходной
сборке, затем прошли после исправления. Дополнительно проверяются Home, новый
документ и явное сохранение при задержке загрузки шрифта.
