Pixprite 0.0.2 добавляет настольное приложение и локальное управление редактором через MCP.

- Единый бандл интерфейса и кодеков; вычислительный Worker остаётся отдельным. Повторных загрузок экранов и диалогов больше нет.
- Анимированная заставка до запуска JavaScript, поддержка reduced motion и повтор после ошибки загрузки.
- Открытие файлов из установленной PWA после восстановления сессии; ошибка одного handle не мешает остальным файлам.
- Настольные приложения на Tauri 2 и системном WebView, без встроенного Chromium/Node.js: отдельные сборки macOS для Intel (x64) и Apple Silicon (arm64), Windows x64, Linux x64; файловые ассоциации и восстановление сессии.
- Одно окно с компактным заголовком Pixprite: кнопки окна слева на macOS и справа на Windows/Linux. Меню остаётся внутри приложения; системное меню оболочки отключено. Старые многооконные сессии объединяются при переносе профиля.
- Компактное закрываемое уведомление о новой версии поверх интерфейса сверху. Не занимает строку, не сдвигает редактор и открывает страницу релиза; скачивание и установка выполняются пользователем.
- Сетевые проверки обновлений выполняются в фоне после готовности редактора и не задерживают запуск.
- Системный диалог сохранения и нативный буфер изображений. Для перехода с Electron добавлен перенос IndexedDB и настроек с сохранением исходного профиля.
- Проекты настольной версии хранятся обычными `.pixprite`-файлами в каталоге данных ОС. Рабочие копии и снимки разнесены по папкам, на главной есть кнопка открытия каталога; существующая IndexedDB переносится с сохранением исходной базы.
- MCP через stdio: создание и выбор документов, пиксели, слои и кадры, команды, PNG preview, сохранение файлов и undo/redo. Пакетные изменения откатываются целиком при ошибке.
- Исправлено ограничение частоты WebKit около 60 fps на macOS: интерфейс запрашивает частоту дисплея. Перетаскивание и ресайз больше не сохраняют настройки на каждом движении; диалоги и панели перемещаются без перерисовки React на каждом событии.
- Панели инструментов, параметры, таймлайн и строка состояния адаптируются к ширине окна: дополнительные действия доступны через меню. Исправлены переносы текста на главной странице, в том числе с крупными шрифтами.
- Встроенные наборы иконок: контурные по умолчанию и пиксельные на выбор; оба доступны офлайн. Пример расширения Duotone добавляет двухцветный вариант. Выбор доступен в меню «Окно → Набор иконок» рядом с языком и темой, а также в настройках; смена применяется сразу.
- Обновлены README и навигация по документации, добавлен пример проекта. Результаты сборок и отчёты собраны в `dist/`.

Инструкции: [настольное приложение и подключение MCP](https://github.com/vicimpa/pixprite/blob/v0.0.2/docs/desktop-mcp.md). `pixprite-mcp.mjs` и соседний `mcp-builtin.mjs` — stdio launcher и payload для Node.js 24+; перед использованием откройте настольное приложение.

Это ранние неподписанные сборки: сертификаты подписи и macOS notarization пока не настроены. Поддержка файловых ассоциаций PWA зависит от браузера и ОС. Проекты веб-версии и настольного приложения хранятся отдельно; переносите их через `.pixprite`.

SHA-256 каждого файла приведён в `SHA256SUMS`.
