срезам Git. Даты в таблице относятся к исходникам, а не к публикации
этих исторических заметок.

Описание 0.0.2 сверено с итоговым деревом тега, включая исправления после
основного релизного коммита `75b5537`. При составлении учтены откаты:
возможности, удалённые до тега, не перечисляются как доступные в выпуске.
