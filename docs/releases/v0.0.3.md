# Pixprite 0.0.3 — общий интерфейс редактора и расширений

Редактор и панели расширений используют общий UI kit на Web Components.
Исправления общих контролов теперь приходят вместе с обновлением Pixprite,
а авторам расширений доступен тот же набор компонентов.

**Дата выпуска:** 1 ноября 2026 года. **Исходники:**
[`v0.0.3`](https://github.com/vicimpa/pixprite/tree/v0.0.3).
[Изменения относительно v0.0.2](https://github.com/vicimpa/pixprite/compare/v0.0.2...v0.0.3).

## Для пользователей

- Исправлены селекты в Game rig: список открывается рядом с контролом,
  не перебрасывает прокрутку вниз и работает после изменения размеров панели.
  Доступны выбор мышью, стрелками и подтверждение с клавиатуры.
- Селекты, поля, флажки, ползунки, меню, диалоги и выбор цвета получили общую
  реализацию в редакторе и расширениях. Прежние HTML-контролы расширений
  автоматически подключаются к тому же поведению.
- Уточнены клавиатурная навигация, закрытие вложенных меню, работа подписей
  полей, required/disabled/readonly, отправка и сброс форм. При ошибке
  обязательного селекта фокус получает его видимая кнопка.
- Незавершённые числовые значения и выражения сохраняются при переносе
  полей между панелью и меню «Ещё», в том числе в WebKit. Перетаскивания
  завершаются при отмене указателя; закрытие и повторное открытие контролов
  освобождает обработчики и восстанавливает состояние.
- Исправлены переносы подсказок на Home при крупном интерфейсе и шрифтах;
  градиенты сохраняют цвет и прозрачность при переключении между WebGL
  и Canvas fallback.

## Для авторов расширений

- Добавлен `@pixprite/ui`: 30 общих custom elements для полей, раскладки,
  меню, диалогов, форм, цвета, перетаскивания, адаптивных панелей,
  виртуальных списков, Canvas, градиентов и иконок.
- Панели и виджеты могут указывать TSX-страницу с React-компонентом в
  `export default`. Новый `@pixprite/ui-react` предоставляет общие контролы;
  хуки импортируются из `react`. JSX компилируется редактором, компонент
  монтируется автоматически и получает подключённый API через props `ctx`.
  HTML и отдельная сборка не нужны. В шаблон расширения добавлен React-виджет.
- Исправлена инициализация уже загрузившегося iframe: виджеты получают API
  и в WebKit, когда событие `load` произошло до подключения моста.
- `@pixprite/ui` и `@pixprite/ui/elements` регистрируют компоненты,
  `@pixprite/ui/legacy` адаптирует существующие HTML-контролы.
  Реализацию предоставляет редактор внутри sandbox; отдельная сборка
  или копия библиотеки в пакете расширения не требуется.
- Компоненты используют нативные поля, события `input`/`change`, формы
  и CSS-переменные темы. Повторные импорты используют одну регистрацию
  компонентов внутри документа.
- React-интерфейс редактора подключён через `@pixprite/ui/react` и адаптеры.
  Изоляция iframe, CSP и разрешения Extension API сохраняются.

Примеры импорта и API: [руководство расширений](https://github.com/vicimpa/pixprite/blob/v0.0.3/docs/extensions/README.ru.md).
Архитектура и измерения: [общий UI kit](https://github.com/vicimpa/pixprite/blob/v0.0.3/docs/ui-web-components.md).

## Сборка и зависимости

- Обновлены зависимости: TypeScript 7.0.2, Vite 8.3.5, React/React DOM 19.3.1,
  styled-components 6.6.0 и связанные библиотеки и типы. Обновлён `bun.lock`.
- Rust Tauri обновлён до 2.12.5 для совместимости с JS API 2.12.4.
  В CI и подготовку desktop-сборки добавлена ранняя проверка совпадения
  major/minor версий Tauri.
- Сборка переведена на настройки Rolldown и Oxc; разрешение путей TypeScript
  использует встроенную возможность Vite. Проверка переводов использует
  совместимый классический AST API из `@typescript/typescript6`.
- Убраны дублирующие реализации контролов и шейдеров, расширена документация.
  Исправлена совместимость `HTMLElement.hidden` с новыми DOM-типами.
  Пример AI assistant обновлён до 0.1.1 после исправления типизации списка чатов.
- Сохраняются один браузерный JS-бандл и самостоятельные Workers. Общий
  runtime UI для расширений входит в измеряемый размер JS; действуют лимиты
  500 KiB для initial и 532 KiB для всего JavaScript (gzip level 9).
  Изолированный React runtime для TSX-страниц добавляет около 76.5 KiB gzip;
  он поставляется редактором и работает внутри sandbox без загрузки с CDN.

## Проверки и совместимость

На итоговом коде UI и зависимостей прошли проверка типов, 289 unit-тестов,
94 браузерных сценария Chromium и 65 WebKit, проверки переводов и расширений,
production-сборка и проверка размера/графа бандла. Один opt-in тест с внешними
Aseprite fixtures пропущен. Отдельно проверены реальные селекты Game rig,
вложенные меню, формы, перенос полей и режим без WebGL.

После обновления версии повторно проверены production-сборка, лимиты и граф
бандла, совпадение версий JavaScript/Rust и `desktop:prepare` (мост Tauri и MCP).
После выравнивания Tauri локально прошли все 9 тестов нативной части Rust
и 9 desktop/MCP-сценариев на macOS Apple Silicon.

Релизный workflow собирает установщики для macOS Apple Silicon и Intel,
Windows x64 и Linux x64, проверяет нативную часть, ресурсы приложения и
desktop/MCP-сценарии перед публикацией. Вместе с установщиками публикуются
`pixprite-mcp.mjs`, `mcp-builtin.mjs` и контрольные суммы `SHA256SUMS`.
Формат документов остаётся `.pixprite` v5 с чтением v3–v5; существующим
расширениям не требуется переупаковка для подключения адаптера HTML-контролов.
Для новых компонентов и исправлений UI обновляется само приложение.
