# План Pixprite 0.0.8 — кисти, штампы и заливка фигур

Составлен 9 ноября 2026 года. Кандидат выпуска 0.0.8 подготовлен по запросу
пользователя на публикацию. Версии приложения синхронизированы на 0.0.8;
сборка и проверка установщиков, публикация и проверка файлов ещё выполняются.
Фактический состав — в [заметках 0.0.8](v0.0.8.md).

Проверка настоящего планшета остаётся открытой; запрос на выпуск не является
подтверждением её проведения. Ограничение явно указано в заметках.

## Состав

Полезные новые части [PR #3](https://github.com/vicimpa/pixprite/pull/3)
перенесены выборочно поверх 0.0.7. Основа — набор масок штампов, окрашивание
пользовательской кисти и динамика угла. Исправления нажима, стабилизатора,
цветового popup и текста из 0.0.7 сохраняются.

После выборочного переноса история PR #3 присоединена отдельным merge-коммитом
со стратегией `ours`: исходные коммиты Elitium (@cc4221) сохраняют авторство
в `main`, дерево уже проверенного редактора не меняется. Это фиксирует завершённую
интеграцию выбранных частей; остальные изменения PR остаются исключёнными.
История присоединена без изменения уже проверенных файлов приложения.
Merge-коммит: [`912d6e5`](https://github.com/vicimpa/pixprite/commit/912d6e539a7b3e3f8b10fe1a439aae85bb4202a4).
GitHub отметил PR как merged; API Contributors подтвердил `cc4221` и 7 вкладов.

| Возможность | Поведение |
| --- | --- |
| Встроенные штампы | Звезда, сердце, искра, алмаз, крест и лист; клик оставляет отпечаток, движение рисует кистью |
| Цвет кисти | Исходное изображение либо текущий основной/фоновый цвет; alpha маски и выбранного цвета перемножаются |
| Преобразование отпечатка | Угол для пользовательской кисти, масштаб от существующей привязки нажима к размеру; nearest-neighbour преобразует изображение вместе с alpha |
| Шаг и одиночный штамп | Одно нажатие — один отпечаток либо штрих с расстоянием 0–1000% от размера кисти; шаг сохраняется между событиями |
| Ручные преобразования | Масштаб bitmap-кисти 1–400%, отражения по X/Y, сброс масштаба/отражений/угла; используется общий `renderPlacement` |
| Полные пресеты | Изображение кисти/узор, нажим, динамика, масштаб, отражения, шаг и режим нанесения; восстановление после перезапуска |
| Обмен кистями | Импорт `.pixbrush`/PNG, экспорт текущей кисти/набора в `.pixbrush` и исходного изображения в PNG; атомарная проверка импорта |
| Динамика угла | Фиксированный угол, направление движения, наклон либо вращение пера; ручной угол служит смещением |
| Сохранение | Признак окрашивания и ID штампа сохраняются в библиотеке и кистях проекта; режим угла — в editor-состоянии и пресетах |
| Фигуры | Заметные кнопки «Контур / С заливкой» для прямоугольника, эллипса и многоугольника; живая заливка до применения |
| Свободная заливка | Существующий инструмент Shape fill показывает заполненный предпросмотр и замыкает границу |

Фигуры с заливкой используют точную геометрическую область: размер или форма
пользовательской кисти не расширяют её границы. Выделение, симметрия и режим
рисования остаются общими механизмами редактора. Одно завершённое действие
отменяется одним шагом истории.

Модуль преобразования из PR переработан: исходный вариант поворачивал только
координаты отпечатка и читал цвета из неповёрнутого изображения. Новая реализация
использует существующий `renderPlacement`, сохраняет цвета и полупрозрачность.
Направление штриха хранится внутри сессии инструмента; неподдерживаемая ориентация
и нулевой наклон пера используют ручной угол.

## Как пользоваться

1. В параметрах карандаша или распылителя откройте «Перо»; в поле «Штамп»
   выберите встроенную форму. Захват кисти из выделения и библиотека работают как прежде.
2. Для пользовательской кисти доступны «Угол» и «Текущим цветом».
   Отключите окрашивание, чтобы рисовать исходными цветами изображения.
3. В «Перо → Динамика угла» выберите источник поворота. Нажим на размер
   и прозрачность включается существующими подписанными переключателями.
4. Для прямоугольника, эллипса и многоугольника выберите «Контур» или
   «С заливкой» в параметрах инструмента. Многоугольник завершайте Enter
   или замыканием к начальной точке.
5. Создавайте кисти текущим рисованием и выделением: `Ctrl+B` / `Cmd+B` либо
   «Перо → Из выделения» вызывает существующую команду. Настройте «Нанесение»,
   «Шаг, %», масштаб и отражения, сохраните полный пресет кнопкой +.
6. В «Перо» доступны импорт и экспорт кистей. Подробности форматов и сценариев —
   в [руководстве по кистям](../brushes.md).

## Границы этого этапа

Клонирование с точки-источника, галерея миниатюр, новый режим фигур с разными
цветами контура/заливки и Smart Shape остаются в бэклоге. Этот перенос не означает
завершение всех ранее предложенных возможностей системы кистей.

Перестройка COLOR, новая схема пересчёта alpha, откаты текста и MCP stdio-прокси
из PR не переносятся. Проверка путей переводов для Windows перенесена отдельно.
Формат пиксельного документа и MCP-команды не меняются.

### Исправление кандидата перед публикацией

Первый кандидат `49ddf73` дважды не прошёл нативный сценарий пакетного импорта
на macOS arm64 в [CI](https://github.com/vicimpa/pixprite/actions/runs/42650149199):
проверки импорта и пикселей проходили, но WebKit выдавал `ResizeObserver loop
completed with undelivered notifications`. Остальные 21 нативный тест, Rust-тесты,
сборка и три других платформы проходили. Повторный запуск не устранил сбой.

Видимая область и панель инструментов обновляли React-состояние непосредственно
при доставке resize-уведомлений. Их пересчёт перенесён в следующий animation frame
с объединением вызовов и отменой при размонтировании. Сообщения рендерера
и строгость тестов сохранены. После локальных проверок тег ещё не опубликованного
выпуска 0.0.8 обновлён для новой полной платформенной сборки; исходный объект
тега кандидата — `4a2a201c692fdce38035d5e97c06f60c35a6f823`.
