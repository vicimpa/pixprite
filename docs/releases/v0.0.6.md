# Pixprite 0.0.6 — нативный MCP и работа с файлами

**Дата выпуска:** 1 ноября 2026 года. **Исходники:**
[`v0.0.6`](https://github.com/vicimpa/pixprite/tree/v0.0.6).
[Изменения относительно v0.0.4](https://github.com/vicimpa/pixprite/compare/v0.0.4...v0.0.6).

## Настольное приложение и MCP

- MCP использует Streamable HTTP и работает на Rust прямо в процессе редактора.
  Установленному приложению больше не нужны Node.js, Bun или внешний stdio-адаптер.
  Клиентам нужно заменить прежнюю команду запуска на HTTP-подключение из настроек.
- Панель MCP доступна из меню и постоянной кнопки внизу настроек. Она показывает
  состояние сервера, автозапуск, порт и готовый JSON подключения с токеном;
  конфигурацию можно скопировать одной кнопкой.
- По умолчанию MCP выключен. `--mcp` принудительно включает его на текущий запуск,
  `--mcp --mcp-port 4321` задаёт другой порт, а `--no-mcp` отключает сервер даже
  при сохранённом автозапуске. Флаги не меняют предпочтения; `--mcp` и `--no-mcp`
  вместе недопустимы. Порт `0` позволяет системе выбрать свободный порт.
- Повторный запуск передаёт файлы в существующий редактор. Относительные пути
  разрешаются от каталога вызывающего процесса; несохранённые вкладки сохраняются.
  MCP завершается вместе с окном без отдельного процесса и задержки ожидания.
- MCP умеет просматривать сохранённые проекты и папки библиотеки, фильтровать их
  и открывать проект по постоянному ID, сохраняя уже открытую рабочую копию.
- Явное изменение размера скрытого окна сохраняется с общей задержкой записи,
  даже если GTK ещё не прислал событие изменения размера.
- Исправлена гонка восстановления сессии: события видимости при запуске больше
  не могут перезаписать вкладки до окончания загрузки. Старые сессии нескольких
  окон восстанавливаются в одном окне.

## Файлы и интерфейс

- Несколько изображений при обычном открытии становятся отдельными документами.
  Импорт последовательности кадров остаётся отдельным действием. Повреждённый
  файл не прерывает открытие остальных; нативные перетаскивания проходят через
  очередь открытия файлов редактора.
- Перетаскивание проектов и папок в библиотеке работает через события указателя,
  в том числе в Tauri, где системное перетаскивание файлов обрабатывает оболочка.
- В небольших окнах и при крупном интерфейсе строки настроек больше не
  накладываются друг на друга. Кнопка MCP остаётся доступной внизу диалога.
  Подпись изменения прозрачности кальки за кадр переведена.

## Расширения

- AI Assistant 0.3.0 получает шесть встроенных навыков: изучение спрайта,
  рисование, локальное редактирование, анимация, палитры и команды редактора.
  Модель получает краткий каталог и загружает нужную инструкцию через `read_skill`.
- Добавлено чтение выделения. Некорректные цвета, размеры и строки пикселей
  отклоняются до изменения документа. Если пользователь переключил документ
  во время ответа модели, дальнейшее выполнение инструментов этого запроса
  останавливается.
- Украинский языковой пакет обновлён до 1.1.1 с новой строкой AI Assistant.

## Проверки

Нативные сценарии используют настоящий WebView со скрытыми окнами, без захвата
фокуса. Проверки без MCP запускаются с `--no-mcp`; проверки MCP используют
встроенный HTTP-сервер. Покрыты флаги, жизненный цикл, единственный экземпляр,
открытие файлов, сохранность сессии и авторизация. Браузерные проверки охватывают
панель MCP, раскладку настроек, библиотеку и инструменты AI Assistant.
