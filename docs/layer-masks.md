# Маски прозрачности слоя

**Слой → Маска слоя…** (также кнопка **Маска** в таймлайне) создаёт один статический канал прозрачности на весь слой и все его кадры. Поддерживаются pixel layers, tilemaps и группы. Маска не заменяет source cel/Image, не меняет linked cels, tile refs или тайлсет. В `.pixprite` остаются редактируемые исходники и отдельный immutable Image маски.

Белый открывает (coverage 255), чёрный скрывает (0), серый задаёт промежуточную прозрачность. Рендер сначала выполняет instance transforms/opacity, floating color pixels и FX слоя/группы; затем умножает полученную alpha на coverage маски с округлением до байта; затем применяет внешние layer/cel opacity, blend и clipping. Цветовые компоненты маски не окрашивают изображение. Маска группы обрабатывает изолированный результат всех её детей, включая их FX и маски.

## Создание

Создание заменяет прежнюю маску одним undo-шагом:

- **Показать всё**: холст заполнен coverage 255, значение вне ресурса также 255.
- **Из выделения**: выбранные пиксели имеют coverage 255, остальные и пространство вне ресурса — 0. Без выделения кнопка недоступна. Контур выделения остаётся обычным независимым ограничением кисти.
- **Из альфы слоя**: снимок alpha другого выбранного слоя на текущем кадре, с его FX, собственной маской и внешней opacity. Соседние слои и alpha родителей не участвуют; собственная скрытость источника не мешает снимку, скрытые дети группы остаются скрытыми. Результат ограничен текущим холстом, с coverage 0 снаружи. Изменения источника/кадра впоследствии маску не меняют. Reference layers и тот же целевой слой не предлагаются.
- **Из основного цвета**: точное совпадение RGB с основным цветом у непрозрачных source pixels текущего кадра. Любая ненулевая alpha выбранного цвета означает сравнение RGB без сравнения степени прозрачности. Прозрачный выбранный цвет вместо этого выбирает все source pixels с alpha 0, игнорируя их скрытый RGB. Совпадения получают 255, остальные и пространство вне ресурса — 0. Для pixel/tilemap слоя берутся размещённые source pixels до FX/маски/внешней opacity; для группы — её изолированный текущий рендер. **Инвертировать маску** превращает сохранение выбранного цвета в его скрытие.

**Включить маску** временно отключает её влияние, сохраняя данные. **Инвертировать маску** вычисляет `255 - storedAlpha`, включая outside. Обе операции меняют только metadata, сохраняют Image ID/буфер и отменяются отдельно. **Удалить маску** также отменяется через undo.

## Редактирование и просмотр

**Редактировать маску** или кнопка **Канал маски / Цветовой канал** переключает цель штатных кистей. Карандаш, фигуры, заливка, градиент и ластик используют отдельный явный mask write path с обычным выделением, симметрией, opacity и stroke undo/Escape. Цвет кисти переводится в coverage по формуле `round((.299 R + .587 G + .114 B) * colorAlpha / 255)`; ластик рисует чёрным с учётом opacity. Кисть не ограничивается source Lock Alpha. Слой и все его родители должны быть видимы и не заблокированы. Кисть на маске группы никогда не пишет в детей; tile mode не превращает mask painting в операции над тайлами.

Редактируется **эффективное** значение после инверсии: белая кисть открывает и при включённой инверсии; запись переводит coverage обратно в storedAlpha. Временное отключение маски не мешает её редактировать и просматривать; для видимого композита снова включите её. Eyedropper и flood-fill region sampling читают mask coverage, независимо от Sample all layers. Переключение канала отменяет незавершённую floating color selection, восстанавливая исходные пиксели. Перемещение/трансформация floating selection, paste, text, blur/jumble и buffer filters в канале маски не выполняются; вернитесь к цветовому каналу для этих операций. Clear/попиксельная инверсия работают с маской.

**Просмотр маски** показывает эффективный канал непрозрачным grayscale, включая отключённую маску; onion skin скрывается. Переключение просмотра/канала — состояние редактора без изменения документа или undo. После открытия документа активен цветовой канал. Generic `getCel`, `canvasPixels`, capture и extension `getPixels`/`putPixels` всегда относятся к source color; отдельные `layerMaskPixels`/`putLayerMaskPixels` используются только там, где явно выбран mask path. Нового молча игнорируемого RPC channel аргумента нет. Export/render API не зависит от выбранного editor channel/view и не экспортирует grayscale preview или brush draft.

## Координаты, память и сохранение

`layer.mask` содержит `{image:{kind:"image",id}, x,y,outside,enabled,inverted}`. `image` указывает в обычную таблицу Image; читается только alpha, writer mask painting записывает RGB 0. Размеры ресурса 1…4096 на сторону, координаты — целые sprite coordinates. Новые маски занимают текущий холст с `x=0,y=0`. Coverage вне прямоугольника — `outside` (целый байт), а не неявное обрезание по canvas/cel.

Resize заранее проверяет размеры/координаты каждой будущей маски до floating commit, checkpoint, преобразования source pixels и allocation. Непредставимый результат отказывает атомарно с локализованной ошибкой в Scale image; уменьшите масштаб или замените маску. При изменении размера холста маска смещается вместе с цветовым содержимым на dx/dy; off-canvas bytes сохраняются. Новая область получает outside. Явный Trim outside пересобирает ресурс под новый холст, используя stored outside. Crop смещает координаты, flip/rotate/scale всего sprite преобразуют и маску (scale nearest-neighbor). Cel-only transforms не двигают статическую маску. При рисовании сохраняются её off-canvas pixels; объединённый ресурс не может превышать 4096 на сторону. Валидная удалённая маска, объединение которой с холстом превысило бы этот предел, остаётся видимой и экспортируемой: редактор показывает предупреждение и отказывает painting/clear до checkpoint, без зависания hover preview. Замена маски через доступное меню снова разрешает рисование; model API также поддерживает явный trimOutside. Маска не раздвигает bounds FX.

Image immutable: history, layer copies и timeline layer clipboard разделяют неизменённый ресурс; painting заменяет только маску целевого слоя. Frame/cel clipboard не переносит статическую layer mask на другой слой; копирование целого слоя переносит её. Приватные mask buffers учитываются в undo budget по backing-store identity, без двойного подсчёта общих ресурсов и без getter-копий. Close освобождает history/cache roots; документ удерживает pixels до завершения сохранений.

Capture/Worker serialization включают mask-only images в таблицу `images`, поэтому существующий content-addressed incremental storage сохраняет маску как отдельный SHA-256 resource, а не base64 в metadata. Enable/invert не требуют повторного кодирования/записи bytes, painting делает dirty только новый mask Image. Atomic transaction, last-good recovery, sessions и snapshots используют те же ресурсы. GC обходит и declared inventory, и фактические Image pointers: неполный inventory не удаляет маску живого документа. Resource shape/digest и mask refs/flags/outside/coordinates проверяются до замены модели. Повреждённый mask resource не подменяет исправную last-good копию.

## Запекание и экспорт

Обычный **Bake FX** запекает FX, сохраняя маску live: она находится после FX. Group FX bake включает маски потомков в raster child, исключает собственную маску группы и сохраняет её снаружи. Поэтому partial frame/range bake не применяет её повторно. Destructive merge/flatten и Layer → Background включают маску в итоговые pixels и удаляют уже запечённую mask metadata; undo восстанавливает источник и маску вместе.

PNG, APNG, sheets, GIF и видео используют общий renderer в Worker и fallback. GIF сохраняет прежние ограничения палитры и бинарной прозрачности. Aseprite не имеет этого mask channel: экспорт запекает pixel/tilemap маски в raster cels, а группу с включённой маской flatten-ит только в экспортной копии вместе с детьми; внешние opacity/blend/clip продолжают действовать один раз. Indexed export с включённой маской консервативно становится RGB для произвольной alpha. Одна alpha-маска сама по себе не требует превращения grayscale в RGB. Исходный документ не меняется.

Модельные тесты покрывают alpha/order/outside, групповые FX bake, indexed/tilemap экспорт, v6 → v7/v8 refusal, round-trip/capture/Worker, ресурсные aliases/history и geometry. Storage regressions проверяют reuse, atomic abort, mask digest corruption, snapshots/last-good/session retention и GC. Production Chromium workflows работают с настоящими pointer pencil/eraser/fill/gradient, Escape, undo/redo, inversion/disable/view, mask factories, group editing, background conversion, reload и PNG pixels.
