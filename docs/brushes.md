# Кисти, штампы и перенос настроек

Возможности выпуска 0.0.8. Результаты проверок — в [плане](releases/v0.0.8-plan.md).

## Создать кисть из рисунка

1. Нарисуйте элемент обычными инструментами Pixprite или откройте изображение.
2. Выделите нужную область. Прозрачные участки выделения останутся прозрачными.
3. Нажмите `Ctrl+B` / `Cmd+B` либо выберите карандаш и откройте **Перо → Из выделения**.
   Используется существующая команда «Кисть из выделения»: исходные пиксели остаются
   на месте, выделение снимается, изображение становится пользовательской кистью.
4. Рисуйте кистью или настройте её в параметрах карандаша. Создавать изображение
   в отдельном редакторе кистей не требуется.

В **Перо → Штамп** также доступны встроенные формы. Текущую кисть можно сохранить
кнопками **Сохранить** в общую библиотеку или **В проект** в настройки документа.
Для сохранения кистей проекта на диск сохраните сам проект обычной командой сохранения.

## Настроить нанесение

| Настройка | Поведение |
| --- | --- |
| Нанесение → Штрих | Наносить отпечатки при движении |
| Нанесение → Один отпечаток | Одно нажатие оставляет один отпечаток; движение и удержание не добавляют новые |
| Шаг, % | Расстояние между отпечатками относительно размера кисти; 100% — один размер, 200% — два |
| Шаг 0 | Сплошной штрих с прежним поведением, включая «Чистые линии» |
| Масштаб кисти, % | 100% — исходное изображение; ручной масштаб 1–400% |
| Отразить кисть по X/Y | Отражение отпечатка без изменения исходного изображения |
| 100% | Сброс масштаба, отражений и ручного угла |
| Текущим цветом | Использовать изображение как alpha-маску текущего цвета вместо исходных цветов |

Масштаб, отражения и угол используют общий механизм преобразования изображения
с nearest-neighbour. Длина стороны преобразуемого изображения ограничена 4096 px.
Привязка нажима к размеру применяется поверх ручного масштаба. Шаг учитывает
этот размер, измеряется в логических пикселях и не зависит от zoom или числа
событий на прямом отрезке. Минимальное расстояние — один пиксель.
В режиме одного отпечатка поле шага отключено.

Карандаш и ластик поддерживают одиночное нанесение и шаг. Распылитель использует
свои существующие ширину/плотность и режим наложения. Перекрытия в одном штрихе
карандаша сохраняют первое нанесение; новый штрих может накладывать цвет снова.
Одно действие остаётся одним шагом undo/redo; Escape отменяет незавершённый штрих.

## Сохранить полный пресет

Настройте кисть, затем нажмите **+** рядом с **Пресет** и задайте имя.
Пресет сохраняет изображение и режим окрашивания/выравнивания, масштаб, отражения,
угол и его динамику, нажим, шаг, способ нанесения, прозрачность и стабилизатор.
Захваченный двухцветный узор тоже переносится вместе с пресетом.

После перезапуска выберите пресет в списке — изображение восстанавливается
без повторного выделения исходника. Пресет обычной кисти восстанавливает обычную
кисть, даже если перед этим был выбран bitmap-отпечаток. Старые пресеты продолжают
работать; новые отсутствующие поля получают совместимые значения по умолчанию,
а прежняя общая настройка нажима остаётся без подмены.

Новые записи библиотеки также запоминают параметры кисти. Изменение текущих
настроек не переписывает ранее сохранённые записи или пресеты.

## Импорт и экспорт

Все действия находятся в **Перо** у карандаша/распылителя:

- **Импорт кистей…** принимает один или несколько `.pixbrush` и PNG. Кисти добавляются
  в общую библиотеку с новыми ID; одинаковые имена получают суффиксы. Существующие
  записи и пиксели документов сохраняются. Первый импортированный элемент выбирается.
- **Экспорт кисти…** сохраняет текущую кисть вместе с её параметрами в `.pixbrush`.
- **Экспорт набора…** сохраняет bitmap-кисти общей библиотеки и текущего проекта.
  У старых записей без параметров сохраняется доступное изображение/метаданные.
- **PNG кисти…** сохраняет исходное RGBA-изображение. Угол, масштаб, отражения,
  окрашивание и динамика остаются настройками и не запекаются в этот PNG.

`.pixbrush` — JSON с `format: "pixprite-brushes"`, `version: 1` и массивом `items`.
Он переносит RGBA-изображения с размерами/alpha, названия, выравнивание,
режим окрашивания и сохранённые параметры. PNG переносит только изображение.
Цвет документа, его пиксели и история не являются частью файла кистей.

Весь пакет проверяется до добавления: неподдерживаемая версия, повреждённые
изображения и недопустимые настройки отклоняют импорт целиком. Отмена выбора
файлов ничего не меняет. Если хранилище не может сохранить библиотеку, импорт
показывает ошибку и не добавляет элементы только во временное состояние.
Лимиты: до 256 кистей, сторона до 4096 px, суммарно до 4096² исходных пикселей
и до 96 MiB входных файлов. Они проверяются и при экспорте `.pixbrush`.
