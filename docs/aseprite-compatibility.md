# Проверка совместимости Aseprite

`bun run test:aseprite` скачивает три оригинальных файла из [официального набора тестов Aseprite](https://github.com/aseprite/aseprite/tree/3669f4774d181d77deb3e6db95fe6df8ca347410/tests/sprites). Ревизия закреплена: `3669f4774d181d77deb3e6db95fe6df8ca347410`. Файлы не включены в репозиторий Pixprite; проверке требуется сеть.

Проверяются импорт и повторное сохранение поддерживаемых данных:

- `tags3.aseprite`: RGB, размеры, 12 кадров, три тега с разным направлением, связанные и пустые ячейки, пиксели;
- `groups2.aseprite`: indexed, порядок и вложенность групп, видимость, корректная обработка старых групп без валидного поля opacity;
- `2x2tilemap2x2tile.aseprite`: размеры, пять тайлов, ссылки tilemap.

Это независимые входные файлы, созданные оригинальным Aseprite, а не собственным encoder Pixprite. Обычный `bun test` пропускает сетевой сценарий; команда `test:aseprite` запускает его явно.

Оригинальный исполняемый файл Aseprite при проверке не запускался: обратное открытие экспорта Pixprite в оригинальном редакторе пока не автоматизировано. Три fixtures не доказывают полную поддержку формата; неизвестные chunks, пользовательские свойства Aseprite, внешние тайлсеты и другие отсутствующие здесь возможности требуют отдельных проверок.
