# Viewport windows

Timeline, Home project/folder cards, palettes and tile canvases use fixed row geometry with two rows/columns of overscan. `visibleRange` returns half-open source indices; rendered arrays never renumber model indices. Full grid tracks or a spacer retain the complete scroll extent. Timeline keeps its sticky tag/frame bands and layer flags, and maps visible row positions through the folded layer order. The existing Home explorer is virtualized; this does not add an editor project explorer.

History, snapshots and validator problems use `VirtualList`: unseen rows start at an estimated height, mounted rows are measured with `ResizeObserver`, and natural text wrapping is retained. Measurement changes keep the first visible row anchored, or keep the bottom anchored when already at the end. Width/font-size changes invalidate measured heights. A focused row/card remains mounted in addition to the viewport window; Tab, arrows, Home and End mount and focus their logical destination after the React commit.

`useViewport` observes scrolling, resizing and moving content within an outer scroller. It reconciles refs after commits so initially absent views (notably pixel documents switching to tilemaps) subscribe when mounted. Home reveal and rubber-band selection use full logical geometry rather than relying on offscreen DOM cards. Tile canvases allocate and paint only visible rows plus overscan; picking and reorder use holder scroll coordinates and original tile indices.

This bounds mounted items and tile canvas memory, not the underlying document, metadata arrays, history, sorting, validator collection or tile-usage computation. Variable-height scroll extents become more accurate as rows are visited. Sticky timeline tag bands remain mounted. No pagination or dependency is added.

Run `bun test src/ui/virtualGeometry.test.ts` for window boundaries and `bun benchmarks/virtualization-check.ts` for an optimized browser build exercising 1000 frames × 100 layers, 1000 history steps/snapshots, 2000 explorer cards and 10000 palette entries/tiles/problems. The browser check verifies bounded nodes/canvas sizes, offscreen navigation and original-index selection/reorder, resize, wrapped-row end anchoring, late tilemap mounting and snapshot restoration. It writes ignored screenshots to `dist/reports/benchmarks/virtualization/`. Fixtures and diagnostic APIs are separate benchmark entries and do not ship in `dist/web/`.
