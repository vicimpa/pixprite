# Pixprite — план развития

Актуализирован 3 ноября 2026 года. В репозитории готовится `0.0.6`; последний опубликованный выпуск — `0.0.5`. Состав ближайшего выпуска согласован.

Это единый список работ. Похожие требования объединены; выполненная основа вынесена в конец. Внутри групп сначала идут задачи, от которых зависят остальные. Порядок разделов отражает пользу и предполагаемый объём, а не обещание включить всё в ближайший релиз.

| Раздел | Как использовать |
| --- | --- |
| [Состав 0.0.6](#release-006) | Согласованный объём ближайшего выпуска и готовность |
| [Небольшие практичные улучшения](#small) | Первые кандидаты при выборе следующей задачи |
| [Основные возможности редактора](#editor) | Полезные функции с изменениями модели, интерфейса или нескольких подсистем |
| [Крупные направления](#large) | Отдельные этапы с предварительным проектированием |
| [Условные и непрофильные идеи](#conditional) | Возвращаться при конкретном пользовательском сценарии |
| [Подготовка выпуска](#delivery) | Повторяемые проверки и оставшаяся документация |
| [Уже выполнено](#completed) | Сохранённые результаты, которые не нужно заново ставить в работу |

`[x]` означает ранее выполненную работу или подтверждённое наличие в коде. `[ ]` — оставшуюся работу либо явно обозначенную проверку существующего поведения. Наличие структуры в модели ещё не означает готовый пользовательский инструмент. Оценки объёма предварительные; дат и согласованных сроков здесь нет.

Рабочие ограничения: одно окно редактора; Tauri 2 и системный WebView; локальный HTTP MCP внутри Rust-процесса; расширения на TS/JS. Установленному приложению не нужны Node.js и Bun. Уведомления о версиях ведут на страницу выпуска; автоматическая загрузка и подмена приложения не планируются. Дополнительные окна требуют отдельного решения.

## Выпуск 0.0.6

Согласованы четыре направления. Реализация и общие проверки завершены: Chromium (155 сценариев), WebKit (22), нативные E2E macOS (22), Rust-тесты (19), unit-тесты (325) и внешние `.aseprite` fixtures прошли. Обновлённый DMG macOS arm64 собран, его контрольные суммы и все 22 сценария на упакованном приложении проверены. Сборки macOS arm64/x64, Windows и Linux проходят desktop CI; установщики публикуются на [странице 0.0.6](https://github.com/vicimpa/pixprite/releases/tag/v0.0.6). Подробные требования остаются в своих группах. Заметки: [0.0.6](releases/v0.0.6.md).

| Направление | Граница выпуска | Состояние |
| --- | --- | --- |
| Завершение текущих изменений MCP и AI Assistant | Общий каталог и исполнитель, адресация документов, revision, атомарные пакеты, независимый контекст агента, просмотр сравнения | Реализовано; основные браузерные и нативные сценарии прошли |
| Неквадратные пиксели | Пресеты и своё соотношение, отображение и ввод, undo/redo, `.pixprite`/`.aseprite`, Preview и экспорт с применением пропорций или без | Реализовано; проверены четыре соотношения, реальный ввод, undo, форматы и экспорт в Chromium, WebKit и нативном приложении |
| Надёжный повтор экспорта | Последние настройки отдельно для документа, обновление после успешной операции, валидация устаревших тегов/слоёв/slices | Реализовано; проверены разные вкладки, перезагрузка, отмена, ошибка и завершение после смены вкладки |
| Явные ограничения `.aseprite` | Матрица текущей поддержки, локальные тесты неизвестных chunks и диагностики, предупреждение об обнаруженной потере данных, защита исходника при сохранении | Реализовано; защита от `overwrite:true` проверена в настоящем MCP, внешние fixtures прошли |

Диагностика `.aseprite` сохраняется в `.pixprite`; пропущенные исходные данные не восстанавливаются. Для экспорта импорта с потерями нативный диалог и MCP требуют новый путь. Полноценные ICC и внешние тайлсеты в этот выпуск не входят.

Именованные export presets, пакетный экспорт нескольких проектов, headless CLI, Lock Alpha, блокировка кадров, маски и новые виды истории предлагается выбирать отдельными этапами. У них больше связанных изменений, чем у исправления повтора экспорта.

Критерии выпуска: согласованный список закрыт, сохранность документов и undo/redo проверены, обязательные проверки проходят, подготовлены заметки и установщики. Версии синхронизированы на `0.0.6`; дата выпуска — 4 ноября 2026 года.

## Основные возможности редактора

Практичные задачи для рисования, анимации и обмена файлами. Каждую группу выбираем отдельно; сквозные изменения требуют проверки UI, расширений, MCP, сохранения и истории.

### Pixel Aspect Ratio

Реализовано для 0.0.6. Свойство документа задаётся при создании и в «Изображение → Пропорции пикселя». Компоненты от 1 до 255 сокращаются до минимального целого соотношения. Рисование, выделение и координаты остаются логическими; холст, Preview, миниатюры и MCP Preview учитывают форму пикселя. Четверть оборота всего холста меняет местами оси соотношения.

- [x] Добавить `pixelRatioX / pixelRatioY` в модель документа.
- [x] Поддержать стандартные соотношения `1:1`, `2:1`, `1:2`, `4:5`, `8:7`.
- [x] Добавить пользовательское соотношение.
- [x] Учитывать ratio в редакторе и Preview.
- [x] Добавить экспорт с применением или без применения ratio.
- [x] Читать и записывать ratio в `.aseprite`.
- [x] Сохранять логические координаты и размеры исходных пикселей.

### Совместимость и безопасное сохранение `.aseprite`

Средний объём для диагностики и тестов, большой — для полной поддержки новых данных. Уже есть три закреплённых внешних fixtures и round-trip-тесты; их границы описаны в [совместимости](aseprite-compatibility.md). Тест неподдерживаемого поля должен проверять диагностику, а не обещать поддержку его редактирования.

## Крупные направления

Полезные возможности, которые требуют отдельного этапа. До реализации определить хранение, миграции, границы экспорта, undo/redo и влияние на расширения и автоматизацию.

## Условные и непрофильные идеи

Не входят в ближайшую очередь. Сначала нужен конкретный сценарий и оценка, нужен ли он ядру Pixprite или отдельному расширению. Идеи сохранены, но их наличие в плане не означает обязательство реализовать.

| Направление | Оценка применимости |
| --- | --- |
| Изометрия, bitmap fonts | Профильные, но специализированные задачи; выбирать по реальным спрайтам и pipeline |
| ICC | Диагностика потери профиля нужна раньше, чем полноценная система управления цветом |
| Нелинейная история | Сначала надёжные линейная история, лимиты памяти и восстановление |
| Свободная компоновка, дополнительные окна | Большой объём UI; дополнительные окна требуют пересмотра принятого ограничения |
| Аудио, lip sync, text layers, CRT preview | Возможные отдельные режимы или расширения; требуют подтверждения пользы для редактора спрайтов |
| Рисование во время playback | Необычный режим с неоднозначной адресацией штриха; нужен явный сценарий |
| Планшетный и мобильный UX | Отдельный интерфейсный проект, а не небольшая адаптация desktop |
| PSD и дополнительные форматы | Только при потребности обмена с конкретными инструментами |
| Legacy FLI/FLC/PCX, эмуляция Lua, CRDT и сервер совместной работы | Сейчас вне фокуса продукта; не ставить в разработку без отдельного решения |
