# Таймлайн

Кадры имеют фиксированную ширину, равную UI cell. Мини-карта, zoom/Fit и отдельные элементы навигации (список тегов, Previous/Next, «только текущий тег», кнопка перехода к кадру) убраны по решению владельца. Для длинной анимации доступны обычная горизонтальная прокрутка, стрелки/Home/End и существующий Go to frame (Alt+G) через меню или status bar.

Теги занимают одну полосу фиксированной высоты. Пересекающиеся теги накладываются, выбранный отображается сверху. Выбрать перекрытый тег можно через контекстное меню пересекающегося тега; пункты содержат имя и исходный диапазон каждого тега. Клавиатурный фокус на кнопке сворачивания также поднимает тег. Выбор диапазона, перетаскивание, изменение границ, свойства и сворачивание работают непосредственно на полосе.

Сворачивание сохраняет исходные индексы кадров. Явный переход раскрывает причины скрытия кадра назначения; playback проходит скрытые кадры без раскрытия. DOM виртуализирует видимые колонки и слои с overscan. Сетка использует полный горизонтальный extent вместо `repeat(frameCount)`, поэтому длинные анимации не достигают ограничения CSS grid tracks. При resize сохраняется исходная позиция в центре viewport, а ранее видимый playhead остаётся доступным. Каждый жест хранит исходные columns, ширину и screen/scroll origin до pointerup.

Состояние выбранного тега и geometry refs хранят документ через WeakRef. Выбор согласуется с изменением/удалением тегов и сбрасывается при смене документа. `timelineReveal` позволяет повторному переходу к текущему кадру прокрутить его в область видимости. Эти view-поля не сериализуются; формат остаётся WRITE v7 / READ v3–v7.

Проверки: `bun test src/core/TimelineNavigation.test.ts src/core/TimelineFolding.test.ts`; production Chromium проверяет одну полосу и доступ к перекрытым тегам, сворачивание и исходные индексы при перетаскивании, 20000 кадров с bounded DOM, переход к последнему кадру и resize, сохранность source pixels и PNG.
