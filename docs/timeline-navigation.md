# Навигация таймлайна

Кадры таймлайна имеют фиксированную ширину, равную UI cell; отдельного zoom и кнопок Fit нет. Высота кадров и слоёв также равна UI cell, теги занимают одну полосу той же высоты. Пересекающиеся диапазоны накладываются; выбранный тег находится поверх остальных, переключение доступно через список тегов. Длинные подписи обрезаются границами тега; полное имя и диапазон доступны в tooltip и списке тегов. При resize сохраняется исходный кадр и дробная позиция в центре viewport; при сворачивании эта позиция отображается внутри placeholder. На краях прокрутка ограничивается реальным extent. При уменьшении viewport ранее видимый playhead остаётся видимым.

Список **Jump to tag** сортирует теги по `from`, затем по исходному индексу. Значение каждого пункта — именно исходный индекс; одинаковые начала и пересечения не объединяются. Previous/Next обходят каждый тег в таком порядке с циклическим переходом. При отсутствии выбора Next ищет следующее начало после playhead, Previous — предыдущее. Явный выбор тега выбирает весь его исходный диапазон, останавливает playback и вызывает `goToFrame(from)`, раскрывая все причины скрытия начала. Выбор сохраняется при переименовании и undo с восстановленными копиями метаданных; удаление выбранного тега снимает выбор. При смене документа view-настройки сбрасываются. Они локальны для открытой панели и не записываются в формат документа.

Active tag — явно выбранный тег, пока он содержит playhead; иначе innermost (самый короткий, при равной длине первый исходный). **Only current tag** ограничивает только отображаемые колонки active tag. Граничный placeholder обрезается по его диапазону. При переходе/проигрывании за границу active tag фильтр следует тегу назначения; вне всех тегов временно показывает весь документ, сохраняя включённый checkbox. Поэтому goto никогда не оставляет playhead вне доступного отображения. При отсутствии тегов список, Previous/Next и checkbox недоступны. Нет преобразования кадров, диапазонов модели, clipboard, loop, playback/export: всё продолжает использовать исходные индексы и существующую семантику playRange. Ручной номер кадра (1-based) использует существующий диалог Go to frame (Alt+G), кнопку панели и status bar; все переходы проходят через `goToFrame`, включая повторный переход к уже текущему кадру.

Мини-карта показывает теги, свёрнутые участки, playhead и viewport. Обычная прокрутка, folds, фильтр и resize синхронно меняют viewport. Нажатие вне viewport центрирует прокрутку, drag внутри сохраняет точку захвата; доступны Left/Right, PageUp/PageDown, Home/End. Это управляет прокруткой, не меняя выбор кадра. Canvas ограничен 4096×96 backing pixels независимо от длины анимации и DPR; смена DPR перерисовывает его. Playhead и viewport — отдельные DOM-overlays, поэтому playback/scroll не перерисовывают всю карту.

## Длинные анимации и точность

DOM виртуализирует видимые колонки фиксированной ширины с overscan, включая свёрнутые placeholders. Редактирование tag/onion границ использует замороженное отображение и исходные кадры. Каждый selection/move gesture также хранит исходные columns, ширину колонки и screen/scroll origin: reveal на pointerdown или смена active-tag crop не подменяет координаты до pointerup. У частично обрезанного фильтром тега скрытая исходная граница не становится resize handle; движение берёт исходный кадр под точкой захвата.

Сетка имеет один полный горизонтальный extent track вместо `repeat(frameCount)`: ограничения браузера на число CSS grid tracks не обрезают длинные анимации. Виртуализируются также слои. DOM и canvas ограничены viewport; исходные массивы, список тегов и фон карты зависят от размера документа. Число пересечений не увеличивает высоту единственной полосы тегов. Mapping/tag layout мемоизированы; карта не перерисовывается на каждом тике playhead.

View-only режимы не участвуют в capture/extension data, pixels/FX, масках, links и экспорте. `.pixprite` остаётся WRITE v7 / READ v3–v7. Единственный новый счётчик `timelineReveal` живёт в Sprite только во время работы редактора и позволяет same-frame goto прокрутить к раскрытому кадру; в сериализацию и history он не входит. Navigation state и geometry refs хранят документ через WeakRef.

Проверки: `bun test src/core/TimelineNavigation.test.ts src/core/TimelineFolding.test.ts`; production Chromium в `e2e/editor.e2e.ts`: фиксированная ширина кадров и pointer source picking, overlapping/equal-start теги, rename/delete/filter/goto, folds/same-frame reveal, двусторонняя minimap/scroll/resize/keyboard синхронизация, 20000 кадров с bounded DOM и доступным последним кадром, persisted source/PNG integrity. Existing folding E2E дополнительно проверяют tag/onion source mapping и drag/drop.

## Bundle

До блока: initial gzip 191414 B, total 424290 B. Измеренный production build после добавления навигации: initial 191434 B (+20), total 428046 B (+3756). Лимит initial остаётся 307200 B; total увеличен с 425984 B (416 KiB) до 432128 B (422 KiB), ровно +6 KiB для навигации/мини-карты. Финальные измерения проверяются `bun run bundle:check`; функциональные графы editor/AI/game-rig и shared-worker gates сохраняются.

Дополнительная проверка владения памятью: `bun benchmarks/history-check.ts` проходит operation/bytes сценарии и настоящий Chromium GC (`document:true`, `snapshot:true`). Исправлен только setup harness: после deliberate `host.dispose()` в transactionFailure следующий независимый close-сценарий создаёт новый host/context; production Host не меняется.
