## Возможности

- **Рисование** — карандаш, ластик, спрей, линии, кривые, фигуры, заливка контура и полигона, заливка с допуском, градиенты с дизерингом, текст, размытие и разброс. Рисование узором, pixel-perfect, стабилизатор, симметрия, свои кисти, библиотека кистей и пресеты инструментов, нажим пера.
- **Выделение** — прямоугольник, эллипс, лассо, полигон, волшебная палочка, по цвету, по непрозрачности слоя; сложение, вычитание и пересечение; перемещение, масштаб, поворот и наклон с точным вводом.
- **Слои** — группы, тайлмап-слои, референсы, обтравка по нижнему слою, режимы смешивания, прозрачность, соло, слияние без изменения видимого результата.
- **Анимация** — кадры с длительностью, теги с направлением и числом повторов, связанные ячейки, onion skin, генерация промежуточных кадров, массовое изменение таймингов, окно превью.
- **Цвет** — режимы RGB, оттенки серого и индексный; генерация переходов (RGB/HSV/OKLab), сортировка и чистка палитры, квантизация, палитры по кадрам.
- **Тайлмапы** — тайлсеты с отражениями и поворотом, поиск дубликатов, счётчик использований, импорт и экспорт тайлсета, экспорт карты в JSON/CSV.
- **Файлы** — собственные проекты `.pixprite` с автосохранением и снимками, чтение и запись `.aseprite`, PNG, GIF, APNG, WebM, ICO/CUR, спрайт-листы с JSON-метаданными, экспорт в ZIP.
- **Рабочая среда** — палитра команд, настраиваемые горячие клавиши, вкладки документов, линейки и направляющие с привязкой, жесты тачскрина и трекпада, светлая и тёмная темы, локализация.

Все проекты хранятся локально в браузере (IndexedDB). Никуда ничего не загружается.

## Разработка

Нужен [Bun](https://bun.sh).

```sh
bun install
bun run dev        # dev-сервер на http://localhost:3355
bun run typecheck  # tsc -b
bun run build      # сборка в dist/
```

### Структура

```
src/
  core/      модель редактора: спрайт, инструменты, команды, форматы, воркеры
  modules/   блоки интерфейса: холст, таймлайн, панели, диалоги, меню
  ui/        переиспользуемые UI-компоненты
  styles/    глобальные стили и переменные тем
public/      статика (иконки)
```

Импорты используют алиас `~/` для `src/`, например `import { state } from "~/core/State"`.

Пуши в `main` собираются и выкладываются на GitHub Pages через CI.

## Принцип чистой комнаты

Pixprite — независимый проект. Он ориентируется на общий набор возможностей существующих редакторов пиксель-арта, но код, алгоритмы, ассеты, иконки и тексты из них не копируются. Форматы файлов, например `.aseprite`, реализованы по публичным спецификациям. Пожалуйста, придерживайтесь того же правила.
