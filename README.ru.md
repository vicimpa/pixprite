## Возможности

| Возможность | Инструменты |
| --- | --- |
| **Рисование** | Pixel-perfect штрихи, фигуры, градиенты, дизеринг, симметрия, свои кисти и нажим пера. |
| **Анимация** | Длительности кадров, теги, связанные ячейки, onion skin, промежуточные кадры и предпросмотр. |
| **Композиция** | Слои и группы, обтравка, режимы наложения, референсы, выделение и трансформации. |
| **Тайловые карты** | Наборы тайлов, отражение и поворот, поиск дубликатов, экспорт карты в JSON/CSV. |
| **Обмен файлами** | `.pixprite`, `.aseprite`, PNG, GIF, APNG, WebM, спрайтшиты и ZIP-архивы. |
| **Настройка** | Встроенные контурные иконки по умолчанию, пиксельный вариант, темы, языки, горячие клавиши и расширения. |

Настольное приложение хранит проекты обычными `.pixprite`-файлами в каталоге данных ОС; рабочие копии и снимки лежат отдельно. Браузерная версия использует IndexedDB. После первой полной загрузки браузерная версия работает офлайн; открытие файлов через PWA зависит от поддержки браузера. Подробнее: [хранилище и резервные копии](docs/storage-and-backups.md), [работа PWA](docs/service-worker.md).

## Настольное приложение и автоматизация

Приложение на Tauri 2 собирается для **macOS, Windows и Linux**. Есть ассоциации файлов, компактный заголовок с кнопками окна, вкладки документов и фоновые уведомления о новых версиях. Локальный **MCP-сервер** позволяет совместимым клиентам читать и менять документы, выполнять команды редактора и экспортировать результат.

Для macOS публикуются отдельные `.dmg`-установщики для **Apple Silicon (arm64)** и **Intel (x64)**.

[Собрать приложение и подключить MCP →](docs/desktop-mcp.md)

## Локальный запуск

Нужен [Bun](https://bun.sh) **1.4.2**, для настольной версии — также **Node.js 24+**.

```sh
bun install --frozen-lockfile
bun run dev
```

Откройте **http://localhost:3355**. Другие команды:

```sh
bun run build          # веб-приложение → dist/web/
bun run preview        # просмотр готовой веб-сборки
bun run desktop:dev    # сборка и запуск приложения Tauri
bun run desktop:build  # установщики для текущей ОС → dist/installers/
```

Подробнее: [разработка](docs/development.md), [проверки](docs/testing.md), [участие в проекте](CONTRIBUTING.md).

## Участие в проекте

Pixprite — независимый проект. Код и графика в изменениях должны быть оригинальными; поддержка форматов основана на открытых спецификациях. Начать можно с [CONTRIBUTING.md](CONTRIBUTING.md).

Проект распространяется под [лицензией MIT](LICENSE).
